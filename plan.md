
# Implementation Plan — Ahmad Shah Portfolio

## Phase 1: Structure
- Create valid semantic HTML.
- Add all required sections and matching IDs.
- Connect the CSS and JavaScript files.

## Phase 2: Design
- Apply the dark navy and neon cyan/purple theme.
- Create the hero layout, photo frame, cards, and buttons.
- Add responsive layouts and animations.
- Avoid overlapping text and images.

## Phase 3: Functionality
- Connect navigation links.
- Implement the mobile menu.
- Add scroll reveal effects safely.
- Add profile image fallback.
- Configure the email link.

## Phase 4: Verification
- Check HTML section IDs and navigation targets.
- Check the image path.
- Test the email link.
- Check desktop and mobile layouts.
- Check the browser console.

## Scope Rules
- Use plain HTML, CSS, and JavaScript.
- Do not add unnecessary libraries or paid services.
- Do not overwrite the user's profile photo.
- Do not claim unperformed tests have passed.

## Final Report
List implemented features, files changed, tests actually performed, and any remaining problems.
