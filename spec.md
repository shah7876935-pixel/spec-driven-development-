
# Specification — Ahmad Shah Portfolio

## Goal
Build a modern, responsive portfolio to present Ahmad Shah's skills, learning journey, projects, and contact details.

## Target Audience
Potential employers, freelance clients, developers, and visitors.

## Visual Design
- Dark navy background.
- Neon cyan and purple accents.
- Glowing borders and modern cards.
- Smooth, subtle animations.
- Professional typography and spacing.
- Responsive design for desktop, tablet, and mobile.

## Required Sections

### FR-01: Navigation
Home, About, Skills, Projects, and Contact links.

### FR-02: Hero
Display:
- Ahmad Shah
- Web Developer & AI Enthusiast
- Short introduction
- Explore My Work button
- Let's Connect button
- Profile image

### FR-03: About
Show an honest biography and learning goals without overlapping elements.

### FR-04: Skills
Show HTML, CSS, JavaScript, and Spec-Driven Development as skills being learned or practiced.

### FR-05: Projects
Show the Personal Portfolio and JavaScript Experiments as learning projects.

### FR-06: Contact
Show shah7876935@gmail.com and a working mailto link.

### FR-07: Profile Image
Load images/ahmad.jpg. Show initials as a fallback if the image cannot load.

### FR-08: Responsive Layout
Support small phones, tablets, laptops, and desktop screens.

### FR-09: Interactions
Include working navigation, mobile menu, hover effects, and safe scroll animations.

## Acceptance Criteria
- All navigation links target existing section IDs.
- Hero buttons navigate to the correct sections.
- No text/photo overlap.
- No horizontal scrolling at widths of 320px, 375px, 768px, and 1366px.
- Email link uses the correct address.
- Content remains visible if JavaScript animations are unavailable.
- No invented work experience or credentials.
- Testing results are reported honestly.
